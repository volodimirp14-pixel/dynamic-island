# CHANGELOG

Формат: [версия] — дата — что изменилось.

## [1.4.0-custom.20] — 2026-11-24
### Исправлено (по просьбе пользователя)
- При перелистывании вкладок цифры и буквы больше не «дорастают» в размере. Причин было две: уходящая/приходящая вкладка уменьшалась до 96,5 % (`kMinScale`) — масштабирование убрано, вкладка теперь только сдвигается и плавно гаснет/проявляется; и сдвиг шёл на дробное число пикселей, из-за чего DirectWrite рисовал буквы без привязки к пиксельной сетке (чуть мельче и мягче), а в конце анимации они «защёлкивались» обратно — теперь сдвиг округляется до целых пикселей экрана.

## [1.4.0-custom.18] — 2026-11-24
### Добавлено
- **Вкладка «Акции»** — последняя в прокрутке колесом. 6 карточек сеткой 2 × 3 (как у монитора железа): тикер, изменение в % (зелёный/красный), цена с валютой, мини-график с заливкой и пунктиром вчерашнего закрытия (на графике «1 день»). В заголовке — период и время обновления, «загрузка…» или «нет данных · проверьте интернет».
- Настройки группы **Stocks**: `Enabled` (вкл), `Range` (1d / 5d / 1mo / 6mo / 1y), `RefreshMinutes` (1–60, по умолчанию 2), `Stock1`…`Stock6` — выпадающие списки из 50 популярных акций мира (США, Европа, Азия, Саудовская Аравия). По умолчанию AAPL, MSFT, NVDA, GOOGL, AMZN, TSLA.
- Данные: `query1.finance.yahoo.com/v8/finance/chart/<тикер>` (запасной `query2`), браузерный User-Agent, без аккаунта/ключа/cookies. Отправляется только тикер и период. Поток `StocksThreadProc`: одна загрузка при старте, дальше обновление только если вкладку смотрели последние 10 минут; смена настроек или открытие вкладки со старыми данными — сразу (не чаще раза в 20 с). При ошибке остаётся последний удачный график. Лог с префиксом `[Stocks]`.
- Код: `kStockCatalog`, `StocksRange`, `StockQuote`/`StocksSnapshot` (`g_state.stocks`), namespace `Stocks` (HTTP, разбор JSON без зависимостей, не зависит от языковых настроек), `Renderer::DrawStocksDashboard`, `DrawStockSparkline`, `FormatStockPrice`.
### Ограничения
- Yahoo Finance официально API не предоставляет; адрес может перестать работать или начать отвечать «429 Too Many Requests». Это будет видно в логе.
- Котировки могут отставать (обычно до 15–20 минут, у некоторых бирж больше). Это не торговый терминал.
- Здесь сеть к Yahoo закрыта, поэтому разбор ответа проверен только на образце JSON, реальный запрос не проверен.

## [1.4.0-custom.17] — 2026-11-24
### Добавлено
- **Liquid Glass (как в iOS)** — новый вариант в «Themes → Backdrop material». Состоит из: тонкой тонировки фона, светлой «линзы» по краю (5 тающих внутрь обводок), блика сверху и слабого отсвета снизу, яркого блика на кромке в левом верхнем и правом нижнем углу, тонкой внутренней кромки («толщина стекла») и тёмной волосяной линии по краю для светлых обоев. Тёмное затенение глубины и контурная рамка в этом режиме не рисуются.
- Настройки: `Themes.LiquidGlassStyle` (tinted — со слабым размытием Windows; clear — без размытия, как Clear в iOS 26.1, работает и без «Эффектов прозрачности»), `Themes.LiquidGlassClarity` (0–100, по умолчанию 60), `Themes.LiquidGlassShine` (0–200, по умолчанию 100).
- `BackdropMaterial::LiquidGlass`, `Renderer::DrawLiquidGlass`, поля `Settings::liquidGlass*`. Размытие даёт тот же `DwmBackdrop` (обычное размытие с тонировкой 8 %). Если размытие недоступно, блики всё равно рисуются поверх обычного фона.
### Ограничения
- Настоящего преломления (искажения картинки за стеклом) нет: Windows не даёт окну доступа к пикселям под ним. Это имитация светом по краям.
- Силу размытия задаёт Windows, мод её не меняет.

## [1.4.0-custom.16] — 2026-11-24
### Удалено (по заданию «Полная очистка», из исходного кода, а не выключено)
- **Анимации переходов развёрнутого плеера**: смена источника, морфинг play/pause, «глубина» кнопок перемотки, «дым» заголовка, смена исполнителя и альбома, переворот обложки. Настройка `ExpandedMediaAnim` (и всё, что её читало). Плеер теперь меняет содержимое сразу.
- **Вращение обложки в свёрнутой пилюле** (`PillCoverAnim`, «диск», «приземление» обложки).
- **Caps Lock**: модуль, пилюля, клавиатурный хук `WH_KEYBOARD_LL` и его поток.
- **Буфер обмена**: модуль, слушатель `WM_CLIPBOARDUPDATE`, превью текста и картинок.
- **Полоса обратного отсчёта** на всплывашках (`StatusCountdownProgress`). Карточки устройств, Bluetooth и Telegram/Discord рисуются в варианте без полосы.
- **Пилюля «Не беспокоить» Windows** (`DoNotDisturbIndicator`). Сигнал WNF оставлен только для `Telegram.RespectWindowsDnD`. Наш «Не беспокоить» острова больше не показывает пилюлю подтверждения: остров сразу сжимается.
- **Тексты песен / караоке**: LRCLIB, дисковый кэш, вкладка Lyrics, иммерсивный режим, строка в свёрнутой пилюле, сдвиг синхронизации (в т.ч. для Bluetooth), подменю и пункты меню.
- **Quick Lookup** (поиск по словарю/Википедии, горячая клавиша).
- **File Tray** (перетаскивание файлов, OLE drag-and-drop, вкладка, пункты меню).
- **Все уведомления Windows, кроме Telegram и Discord**: обычная карточка уведомления (`DrawNotification`), перехват окон через shell hook (`CaptureShellNotification`, `IsLikelyToastWindow`, `RegisterShellHookWindow`, `TaskbarCreated`) — из-за него появлялись «уведомления» при закрытии программ; настройка `NotificationRespectDnD`; поиск иконки приложения `FindAppIconByName`; поле `icon` в `NotificationSnapshot`.
- Переводы (`Loc`) для удалённых подписей, описание удалённых функций в README мода.
### Сохранено
- Telegram и Discord: слушатель уведомлений, распознавание по `LastNotificationAddedTime`, подавление баннеров, запасной путь `ToastWatcher` для Telegram, игровой режим, клик по карточке.
- Часы, погода, медиаплеер, календарь, монитор железа, основная анимация острова, «Не беспокоить» острова (тумблер, меню, Ctrl+Alt+N).
### Технически
- ~9 200 строк удалено (25 944 → 16 736). Новых ошибок компиляции (без WinRT) нет; неиспользуемых функций и переменных после удаления не осталось (проверено сравнением упоминаний до/после).
- Состояние «Не беспокоить», бэкап баннеров и прочие сохранённые значения не трогались.

## [1.4.0-custom.6] — 2026-11-24
### Найдено (по логу пользователя)
- Новые уведомления видны (`NEW id=2615`), но `app='?' aumid='?'`: `UserNotification.AppInfo()` бросает исключение для не-Store приложений (Telegram Desktop). Оригинальный код из-за этого молча выбрасывал уведомление целиком, а Telegram не распознавался.

- Неизвестное приложение распознаётся как Telegram по отметке Windows `Notifications\Settings\<AUMID>\LastNotificationAddedTime` (± 5 с от времени создания уведомления). Если Windows такую отметку не ведёт — по признаку «Telegram запущен». Решение пишется в лог: `[Notif] unknown app -> ...`.

## [1.4.0-custom.5] — 2026-11-24

## [1.4.0-custom.1] — 2026-11-24

### Добавлено
- **Сообщения Telegram в острове**: аватар-инициалы, имя, текст, группы («Отправитель: текст»), до N сообщений в одной карточке, «+N», настраиваемое время показа, клик открывает Telegram.
