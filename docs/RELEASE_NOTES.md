**Dynamic Island для Windows 1.0.0** — первая полная версия самостоятельной программы (без Windhawk).

Остров в верхней части экрана: музыка с обложкой, спектром и перемоткой, сообщения Telegram и Discord, Bluetooth-устройства с зарядом наушников и геймпадов, погода, акции, таймер фокусировки, экранное время, умный игровой режим и оверлей FPS/CPU, громкость, яркость, батарея, «Не беспокоить». Остров можно передвигать мышью (зажать на полсекунды), настройки — в окне Launcher.

### Как установить
1. Скачайте `DynamicIsland-1.0.0-win-x64.zip` ниже (раздел **Assets**) и распакуйте в любую папку.
2. Запустите `DynamicIslandLauncher.exe` → «Запустить». Для запуска вместе с Windows включите «Автозапуск».

Нужна Windows 10 или 11 (64 бит). Программа не подписана платным сертификатом, поэтому Windows SmartScreen может предупредить при первом запуске: «Подробнее» → «Выполнить в любом случае».
