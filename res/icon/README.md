# Иконка программы

- `island-pro.svg` / `island-trial.svg` — векторный оригинал (256×256, прозрачный фон): чёрная «таблетка» острова и точка состояния. Pro — зелёная точка, пробная — красная.
- `*-small.svg` — вариант для 16–32 px: без тени и свечения, толще ободок, крупнее точка (чтобы читалось на панели задач).
- `island-pro.ico` / `island-trial.ico` — собраны из SVG: 16, 20, 24, 32, 40, 48, 64, 96, 128, 256 px (PNG внутри ICO).

Пересобрать после правки SVG: `cd res/icon && python3 ../../tools/make_icons.py` (нужны `rsvg-convert` и Pillow).
