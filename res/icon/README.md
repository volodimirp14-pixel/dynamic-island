# Иконка программы

- `island-pro.svg` / `island-trial.svg` — векторный оригинал (256×256, прозрачный фон): плоская чёрная продолговатая «таблетка» острова и круглая точка. Pro — зелёная (#30D158), пробная — красная (#FF453A). Без теней, ободка и свечения.
- `*-small.svg` — тот же рисунок для 16–32 px: чуть толще полоса и крупнее точка, чтобы читалось на панели задач.
- `island-pro.ico` / `island-trial.ico` — собраны из SVG: 16, 20, 24, 32, 40, 48, 64, 96, 128, 256 px (PNG внутри ICO).

Пересобрать после правки SVG: `cd res/icon && python3 ../../tools/make_icons.py` (нужны `rsvg-convert` и Pillow).
