# Иконка программы

- `island.svg` — векторный оригинал (256×256, прозрачный фон): плоская чёрная продолговатая «таблетка» острова и зелёная точка (#30D158). Без теней, ободка и свечения.
- `island-small.svg` — тот же рисунок для 16–32 px: чуть толще полоса и крупнее точка, чтобы читалось на панели задач.
- `island.ico` — собран из SVG: 16, 20, 24, 32, 40, 48, 64, 96, 128, 256 px (PNG внутри ICO).

Пересобрать после правки SVG: `cd res/icon && python3 ../../tools/make_icons.py` (нужны `rsvg-convert` и Pillow).
